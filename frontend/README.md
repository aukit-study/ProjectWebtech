# TurnPro

โปรเจกต์เว็บแอปพลิเคชันชื่อ TurnPro

## คำอธิบาย

เว็บแอปนี้ประกอบด้วยหน้า HTML และไฟล์ JavaScript/CSS สำหรับจัดการระบบผู้ใช้และหน้าแอดมิน เช่น:

- `index.html` - หน้าหลัก
- `login.html` - หน้าเข้าสู่ระบบ
- `profile.html` - หน้าข้อมูลผู้ใช้
- `admin.html` - หน้าแอดมิน
- `classroom.html` - หน้าแสดงห้องเรียน
- `css/style.css` - สไตล์สำหรับหน้าเว็บ
- `js/main.js` - สคริปต์หลักสำหรับแอปพลิเคชัน
- `js/login.js` - สคริปต์สำหรับการเข้าสู่ระบบ
- `js/profile.js` - สคริปต์สำหรับหน้าข้อมูลผู้ใช้
- `js/admin.js` - สคริปต์สำหรับหน้าผู้ดูแลระบบ
- `js/classroom.js` - สคริปต์สำหรับหน้าห้องเรียน
- `js/state.js` - จัดการสถานะหรือข้อมูลภายในแอปพลิเคชัน

## วิธีใช้งาน

1. เปิดไฟล์ `index.html` ในเบราว์เซอร์
2. หากต้องการทดสอบการเข้าสู่ระบบ ให้ไปยัง `login.html`
3. ตรวจสอบการทำงานของแต่ละหน้าจากลิงก์หรือเมนูภายในเว็บ

## หมายเหตุ

- หากต้องการรันในสภาพแวดล้อมเซิร์ฟเวอร์ ให้ใช้ Live Server หรือเซิร์ฟเวอร์แบบสแตติก เช่น Python HTTP server
- ปรับแต่ง CSS และ JS ได้จากไฟล์ในโฟลเดอร์ `css` และ `js`
